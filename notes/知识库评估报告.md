## 二、必须修的硬问题（均已回原文核对）

### 1. EXP01 概览把 LiNbO₃ 写成"双轴"，正文又写"单轴"

```
EXP01:14  - **电光晶体**：铌酸锂（LiNbO₃），双轴晶体
EXP01:38  > 无电场时 LiNbO₃ 为单轴晶体，折射率椭球描述折射率随光传播方向的变化关系
EXP01:96  文字描述版：无电场时，LiNbO₃ 是单轴晶体
```

概览是最短、最容易被检索命中的块，**学生问"LiNbO₃ 是什么晶体"会先得到错误答案**。

→ 改：L14 改为"单轴（负单轴），加电场后产生感生双轴"。全库搜"双轴"只保留"感生双轴"。

### 2. 同一台 WGD-3，缝宽零点不确定度两篇差 5 倍

```
EXP05:197  > 零点不确定度约为 ±0.01mm，若取 0.01mm，相对误差达到 100%，失去意义
EXP05:198  > 0.02mm：相对不确定度约 50%，勉强可接受
EXP06:215  | C003 | ⚠️ 操作 | 缝宽最小值从 0.2mm 开始…机械零点不确定度约±0.05mm，太小时相对误差过大
EXP06:246  若取 0.01mm，不确定度/测量值 = 500%
```

同一台仪器不可能同时是 ±0.01 和 ±0.05。**0.01mm 更像鼓轮分辨率，0.05mm 更像含回程差的重复性。**

→ 改：拆成"鼓轮分辨率 0.01mm"与"零点重复性 ±0.05mm（含回程差）"两个字段，用 5 次开合实测后全库只留一组数。

### 4.2 单块模板

```markdown
### C002 信号强度不得超过 1000（WGD-3 + PMT）
- 适用：第二、三周所有扫描测量
- 做法：先测 (1.0,1.0) 极端组合；软件计数 >1000 时先降负高压，再继续
- 原因：1000 是 PMT 线性区上限，超过后计数不再成正比，长时间超限加速老化
- 后果：数据失真，严重时损伤 PMT
- 口语版：测之前先看软件上的信号数字，不要超过一千；超了就把负高压降下来再测。
```

公式块：

```markdown
### E001 半波电压
- 适用：LiNbO₃ 横向调制，激光垂直入射
- 公式：Uπ = λd / (2 n₀³ γ₂₂ L)
- 读法：半波电压等于激光波长乘电极间距，除以二倍寻常折射率三次方、电光系数与晶体长度的乘积
- 用途：由测得的 Uπ 反算 γ₂₂
```

### 4.3 切块参数

| 块类型 | 目标字数 | 上限 | 切法 |
| --- | --- | --- | --- |
| 概览 | 120–180 | 200 | 1 块 |
| A 原理 | 150–300 | 350 | 一原理一块 |
| E 公式 | 120–220 | 300 | 一公式一块（公式+读法） |
| B 步骤 | 200–320 | 400 | 一阶段一块，步骤 ≤6 |
| C 注意 | 80–150 | 180 | 一条一块 |
| F/G 问答 | 150–300 | 350 | 一问一块 |
| H 错误 | 150–250 | 300 | 一例一块 |
| I 其他 | 150–300 | 400 | 一主题一块 |

⚠️ **关键**：当前 128 个 `###` 中位长度只有 219 字。如果 RAGFlow 用默认 512 token 的 General 切块，**会把 2–3 个 `###` 压进同一块**，标题边界和"一问一答"结构都会丢。要么把块上限压到 320 字，要么启用按标题切分。

### 4.4 十条硬规则

1. 一块一事实；150–320 字，上限 400 字，超过就拆
2. 标题 = 实验缩写 + 对象 + 结论（`C002 信号上限 1000（PMT）`）
3. 块首句重述条件，禁止代词和跨块引用
4. C 类一条一块；表格 ≤4 行
5. 正文不出现 `[来源]`、emoji、`>`、`**`；来源进 metadata
6. 每条公式必须有中文读法
7. 原始 ASR 引语不进索引
8. 每篇首页一个概览块（实验名/仪器/周次/目标/安全）
9. I 类只放报告要求/评分标准/数据表模板
10. 文档 `title` = 实验名，保证每块都带实验上下文
