以下步骤只改需要操作的对象。尤其在“模型配置”和“参数字典”中，某些配置可能被多个智能体共用。

## 3. 添加智能体并完成基本配置

1. 在顶部打开“智能体管理”，点击首页的“添加智能体”。
2. 输入智能体名称，点击“确定”。新智能体会出现在首页卡片列表中。
3. 点击该卡片的“配置角色”。按需要填写昵称、角色介绍（系统提示词），选择现有的 VAD、ASR、主语言模型、TTS 等。页面也提供角色模板，只有确实要套用模板时再选择。
4. 点击“保存配置”。页面提示保存后设备需要重新连接或重启，才能读取新配置。
5. 如需把设备交给该智能体，进入卡片的“设备管理”查看或绑定设备。**添加智能体本身不会自动把已有设备改绑过来。**

本项目另有“未知设备首次连接后自动关联到学生小智”的服务端逻辑。因此，给另一智能体做验证时，要确认测试设备实际显示在目标智能体的设备列表中。

## 4. 添加或更换 ASR 模型

“新增模型配置”和“把模型选给某个智能体”是两个步骤。以下页面需要能看到顶部“模型配置”的账号。

1. 进入“模型配置”，在左侧选择“语音识别”。先搜索现有模型，避免重复创建同一配置。
2. 如需新增，点击“新增”。填写“模型名称”“模型编码”，选择“供应器”；“调用信息”字段会随供应器变化，按项目实际模型服务的参数填写。需要使用时保持“是否启用”为开启，然后保存。
3. 返回模型列表，确认新配置已出现。需要调整时使用该行的“修改”；“创建副本”可保留原配置再调整。
4. 回到“智能体管理” → 目标智能体“配置角色”，在 **ASR/语音识别** 下拉框选择新模型，点击“保存配置”。让相应设备断开并重新连接后再使用。



## 5. 新建、更新和关联 RAG 知识库

### 5.1 新建知识库（已有知识库时跳过）

1. 进入顶部“知识库”页面，点击“新增”。填写知识库名称、描述，并选择一个 **RAG 模型**，然后确认。RAG 模型来自“模型配置”左侧的“知识库”分类；若下拉列表为空，需要由有权限的同学先配置它。
2. 新知识库出现在列表后，确认“启用”开关处于需要的状态。点击该行“管理文件”进入文档页面。

### 5.2 给已有知识库添加或更新资料

1. 进入顶部“知识库” → 找到目标知识库 → “管理文件”。先核对页面顶部的知识库名称，避免上传到别的库。
2. 点击“新增”，选择或拖入文件，确认上传。页面列出的常见格式包括 PDF、DOC/DOCX、TXT、MD、CSV、XLS/XLSX、PPT/PPTX；一次批量上传上限以当前页面提示为准。
3. 上传成功后在文档列表找到文件，点击“解析”。等状态变为“完成”，检查切片数，并可点击“查看切片”查看解析后的内容。上传成功仅表示文件提交成功；要让内容用于检索，还需确认解析状态。
4. 点击“召回测试”，输入一个能在新资料中找到答案的问题，查看返回的切片及内容。这里检查的是检索结果，不等于小智最终回答质量。
5. 若是在替换旧资料，先确认新文件解析和召回结果，再决定是否通过文档列表删除旧文件，避免新旧版本同时参与检索。页面没有“一键覆盖同名文档”的明确入口。

按本地代码，智控台上传会经管理 API 传给 RAGFlow，并在 RAGFlow 中解析、切块；正常成功后不需要在 RAGFlow 再传一遍。需要核对线上目标库时，可在校园网访问 RAGFlow 历史地址 `http://10.92.2.194:8880`；它与智控台是两个界面，登录信息可能不同。

### 5.3 让智能体使用知识库

1. 回到“智能体管理” → 目标智能体“配置角色” → “编辑功能”。
2. 在可选功能中查找名称带 **`[知识库]`** 的目标知识库，选中并保存功能配置；然后在角色页点击“保存配置”。知识库要处于启用状态，且属于当前账号可见范围，才会出现在该列表中。
3. 让该智能体的设备重新连接，再检查实际问答。**新建知识库或上传文件不会自动改变每个智能体的知识库关联。** 如果只是给已关联的同一知识库增补文档，通常无需重新选择知识库，但仍要确认解析与问答结果。
